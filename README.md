SSBot — Car Listings Parser

SSBot is a simple project for parsing car listings from SS.com.

Description:

The project collects car listings from ss.com and filters them based on user-defined parameters. It is designed to track new ads and notify users when matching listings appear.

How It Works:

The parser requests pages with car listings from ss.com
Extracts relevant data (title, price, link, etc.)
Applies filters such as brand, model, price, and other parameters
Compares results with previously seen listings
Returns or sends only new matching ads

Notes:

This is a simple parsing project intended for learning and personal use
No persistent storage is used by default, possible future improvements :)
